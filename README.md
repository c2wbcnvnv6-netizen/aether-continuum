# Aether — The Continuum

Immersive landing page and living showcase for **Aether**, a state-of-the-art product vision for a unified creative continuum for website development, design, UI/UX, and production.

**Aether** is the platform where design, code, collaboration, AI, and deployment exist as different views of the same living system.

This page itself embodies the Continuum aesthetic: deep, luminous, continuous, and carefully crafted.

## View / Deploy
- Open `index.html` directly, or
- Deploy to Vercel, Netlify, Cloudflare Pages, or any static host.
- Compatible with local hot-reload / auto-update servers.

## Features in this version
- Living particle atmosphere with mouse reactivity
- Early-access form (frontend)
- Scroll progress indicator
- Glassmorphic capability cards
- Reduced-motion support
- Open Graph / Twitter meta tags
